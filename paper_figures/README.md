# Paper figures — traceability

This directory exists purely for **traceability**: it maps each figure used in the (private)
thesis/paper manuscript to the code that produced it. It does **not** include the paper's LaTeX
source, which is developed separately and is not part of this repository.

## `scripts/`

- `reproduce_figure3.py` — the only standalone, directly runnable figure script (`if __name__`
  entry point). Writes into `../img/` using a path relative to its own location, so run it from
  inside `scripts/`.
- `geotrans.py`, `system.py` — its dependencies (forward model + default system configuration).
- `geotrans2.py` — a further, independently-maintained copy of the forward model kept alongside
  the others for reference; not imported by `reproduce_figure3.py`.

## Regenerating

```bash
cd paper_figures/scripts
python3 reproduce_figure3.py
```

For the other figures, rerun the corresponding `pipeline/` notebook (see
[`../pipeline/README.md`](../pipeline/README.md)) and copy the relevant output PNG here manually —
there is currently no automated "publish figure to paper_figures/" step.
